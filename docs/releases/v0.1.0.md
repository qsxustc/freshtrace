# FreshTrace v0.1.0

**[Published GitHub Release](https://github.com/qsxustc/freshtrace/releases/tag/v0.1.0)** · **[Download full package](https://github.com/qsxustc/freshtrace/releases/download/v0.1.0/freshtrace-v0.1.0.zip)** · [SHA-256 checksums](https://github.com/qsxustc/freshtrace/releases/download/v0.1.0/SHA256SUMS.txt) · [Live lab](https://qsxustc.github.io/freshtrace/)

FreshTrace turns HTTP cache response headers into an interactive timeline. Compare two policies under the same scenario and inspect why a private or shared cache can reuse a response, needs validation, or must fetch from the origin.

## Included in this release

- An offline browser workbench with English and Simplified Chinese interfaces, A/B policies, elapsed-time controls, private/shared timelines, and decision explanations.
- Presets and scenario controls for origin failure, authenticated requests, and Vary matching.
- JSON scenario download/import and Markdown report export.
- A zero-dependency Node.js CLI that reads local header text, a bare Cache-Control value, or a JSON header object; accepts optional capture clocks; and outputs Markdown or JSON.
- A shared deterministic analysis engine for response caching directives, explicit freshness, Age, validation, supported stale windows, authentication permission, and variant matching.
- Runnable examples in `samples/`, bilingual setup documentation, model documentation with RFC references, contribution and security guidance, and an MIT license.
- A static build, release packaging script, CI workflow, and configurable GitHub Pages workflow.

## Try the examples

From the repository directory with Node.js 20 or later:

```sh
npm start
node bin/freshtrace.js samples/cdn-response.json --elapsed 30
node bin/freshtrace.js samples/origin-outage.json --elapsed 150 --origin-error
```

Import [`browser-vs-cdn.scenario.json`](../../samples/browser-vs-cdn.scenario.json) in the browser for a complete A/B comparison.

## Validation

The automated suite covers 42 checks across core analysis, timeline behavior, scenario validation, and CLI integration. Coverage includes time boundaries, malformed input, private/shared differences, and file-handling behavior. Desktop and mobile screenshots of the actual interface are included in [`docs/images/`](../images/workbench.jpg).

The shared engine and CLI use the same model; a browser result and a CLI result should be compared using identical headers and scenario options. The release commit passed the [Node.js 20, 22, and 24 CI matrix](https://github.com/qsxustc/freshtrace/actions/runs/38573617461) and [GitHub Pages deployment](https://github.com/qsxustc/freshtrace/actions/runs/38573617610).

## Model limits

This release evaluates a complete GET 200 response with a matching URL and unchanged stored representation. Non-200 pasted status lines are rejected. It does not make live requests, infer a heuristic TTL, apply request-side cache directives, or predict provider-specific overrides.

Absent capture clocks, a valid response Date is treated as receipt with zero transit delay. Stale-serving windows represent permission under the stated model; they do not guarantee that a particular browser or CDN implements or chooses that behavior. See [MODEL.md](../MODEL.md) for the complete assumptions and conservative choices.

Scenario and CLI JSON exports include supplied headers. Markdown omits the full header block, but warnings can contain input-derived snippets. Review an export before sharing it.

## Distribution

`npm run build` writes the static app to `dist/`. `npm run package:release` creates `release/freshtrace-v0.1.0.zip` using the system `zip` command. Source distribution does not require npm registry publication; the package is marked private to prevent accidental publication.

The [GitHub Release](https://github.com/qsxustc/freshtrace/releases/tag/v0.1.0) is published with `freshtrace-v0.1.0.zip` and `SHA256SUMS.txt`. The [successful release workflow](https://github.com/qsxustc/freshtrace/actions/runs/38577303096) built the package from the immutable `v0.1.0` tag. All 37 packaged source files match the tag byte for byte; all 12 static build files match their corresponding source files. The package includes the tagged documentation, while later publishing instructions and download links live on `main`.

Download both assets into the same directory and verify before extracting:

```sh
# macOS
shasum -a 256 -c SHA256SUMS.txt
# Linux
sha256sum -c SHA256SUMS.txt
```
